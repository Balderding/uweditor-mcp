# uweditor-mcp

This is only a fork of [Karl Clinckspoor's Underworld Editor](https://github.com/KarlClinckspoor/UltimaUnderworldEditorAvalonia),
made to add an MCP server to it (tools that let an AI assistant edit levels while you watch). The work
is offered back to him: [issue #3](https://github.com/KarlClinckspoor/UltimaUnderworldEditorAvalonia/issues/3).

For the editor itself, its downloads and its documentation, go to
[the original repository](https://github.com/KarlClinckspoor/UltimaUnderworldEditorAvalonia).

The MCP work is on the branch [`mcp-server`](https://github.com/Balderding/uweditor-mcp/tree/mcp-server)
([its changes](https://github.com/KarlClinckspoor/UltimaUnderworldEditorAvalonia/compare/main...Balderding:uweditor-mcp:mcp-server)).
